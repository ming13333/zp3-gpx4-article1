# ZP3–GPX4 Extracellular Immune-Suppression Axis — Article 1

## Scope
Standalone code & data repository for **Article 1** of the ZP3–GPX4 extracellular immune-suppression axis project (migration of the *Cell* 2026 GPX4–ZP3 axis into neuro-oncology / glioblastoma). This repository contains **only** the analysis code, frozen result tables, and submission-grade figures for Article 1.

## Directory structure
- `article1/` — manuscript-specific analyses
  - `scripts/`  — analysis scripts
  - `results/`  — **frozen result tables** (numerical truth; do not edit by hand)
  - `figures/`  — submission-grade SVG figures
  - `reports/`  — audit / reference-verification reports

- `shared/` — shared utilities (scripts, fetch, data, docs) copied in for self-containment
- `LICENSE`, `requirements.txt`, `environment.yml`

## Reproducibility
Frozen tables under `article1/results/` are the source of truth. Methodology audits live in `shared/docs/`. Regeneration scripts are in `article1/scripts/` and `shared/scripts/`.
